# MotionCode IDE
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
React, TypeScript, Vite, Monaco, WebGL2, Zustand, IndexedDB. User supplied stack.
## Users
Creators writing typography PV and motion graphics in code.
## Product Purpose
MotionScript source becomes live visuals through AST, Motion IR, generated JavaScript and a scene graph renderer.
## Capabilities and Constraints
Code is the source of truth. Portable .motion projects embed UUID-addressed assets. Group-local GLSL, contextual completion and arbitrary-time preview are central. Initial release prioritizes execution over decoration.
## Brand Commitments
MotionCode IDE, a video-oriented VS Code + Processing + GLSL Sandbox; user-specified media/editor/preview and lower timeline layout.
## Product Principles
Executable features; explicit time; extensible boundaries; diagnostics in source coordinates.
