# MotionCode workspace

User direction: simplify information density and use a gray base. The creation workspace is functional, with media / source / preview visible initially. Supporting panels open from the toolbar on demand.

Neutral charcoal surfaces, restrained separators, gray controls, muted syntax colors. Color belongs primarily to rendered media. Compact Inter UI typography and monospace source / technical inspection. No dashboard metrics in the default view. Timeline, uniform controls, diagnostics, search and compiler inspection remain accessible through Panels.

Drawable timing is absolute t1–t2, shown as a timeline interval. Project duration remains a project setting.

The project-space origin is the center of the frame. X points right and Y points up (down is negative); pointer conversion and selection overlays share this convention.

Anchor points are pixels relative to each object center, default [0, 0], +Y up. All public drawing, pointer and GLSL pixel coordinates share the centered convention.
